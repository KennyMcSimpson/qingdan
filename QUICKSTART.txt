Edgewise 1.4.0 — Quick Start (Windows x64 Portable)
===================================================

Edgewise (formerly Qingdan) is an ambient Windows deadline bar that stays
within sight without getting in the way. Completely offline — no account,
no cloud sync, no telemetry.

HOW TO LAUNCH
-------------
1. Extract the entire ZIP archive to a permanent folder (do not run from inside
   the ZIP preview).
2. Double-click "Edgewise.exe" (or "Launch-Edgewise.cmd").
3. Keep all neighboring runtime files beside Edgewise.exe.

AUTOMATIC MIGRATION FROM QINGDAN
--------------------------------
If you previously used Qingdan, Edgewise automatically copies your existing
tasks, settings, and snapshots from %APPDATA%\Qingdan into %APPDATA%\Edgewise
on first launch. Your original Qingdan folder is left completely untouched.

KEY FEATURES
------------
- Natural-Language Quick Capture (100% offline):
    "Submit draft fri 18:00 !"             -> Friday 18:00, marked important
    "Review PR in 30m" / "in 3 days"       -> Relative deadline
    "Send slides by eod // check table 2"  -> 18:00 + inline note
    "Conference paper Dec 5th"             -> Ordinal month date
    "Ship report next week"                -> Next Monday 09:00
    "Standup weekdays 09:00"               -> Mon-Fri recurring routine
    "pin: Always verify checksums"         -> Pinned note on the top shelf
    Click "Raw" in the live preview bar to keep your exact literal title.
- Drag & Drop URL -> 1-Click External Link Loop:
    Drop any browser URL onto the window or 46px edge tab to generate a clean
    title while preserving the full URL in notes. Open http(s) links in 1 click
    from any row or from the link pill inside the task editor.
- Screen-Share Stealth (Eye-Off button):
    Hides Edgewise from Zoom, Teams, Discord, OBS, and Windows screenshots
    while staying visible to you.
- Ghost Click-Through Mode (Ctrl+Alt+G):
    Semi-transparent click-through overlay over fullscreen IDEs or PDFs.
    Press Ctrl+Alt+G, Ctrl+Alt+Q, or click the system tray icon to exit safely.
- Adjustable Focus Strip (Crosshair button on any task or Compact strip):
    Pause to cycle 15 / 25 / 45 / 60m presets, click +5m to extend anytime,
    track elapsed progress on a subtle 2px bar, and complete in 1 click.
- Hover-Overlay Actions, +1w Snooze & Routine Skip:
    Hover any row for +1h / Tmr / +1w snooze, Skip on routines (advances
    without cluttering Completed), Focus, and link-open actions — all undoable.
- Quiet Mode (15 / 30 / 60m):
    Hides the window and suppresses desktop alerts until the break ends or you
    resume from the tray; configure the default break duration in Settings.
- Export Tasks as Markdown (.md) or JSON Backup from Settings.

KEYBOARD SHORTCUTS
------------------
- Ctrl+Alt+Q   : Show / dismiss Edgewise (tucks to edge tab if Auto-tuck is on)
- Ctrl+Alt+G   : Toggle Ghost Click-Through overlay
- Ctrl+1 .. 5  : Switch tabs (All, DDL, Repeat, Pinned, Done)
- Up / Down    : Select visible task rows (Enter edit, Space complete, f focus)
- Ctrl+N       : Open Detailed Task Editor (Ctrl+Enter saves from notes too)
- Ctrl+F       : Search titles and notes (with cross-tab match hints)
- Ctrl+Z       : Undo last task action
- Esc          : Close search / toast / selection, or dismiss to edge tab

DATA & PRIVACY
--------------
Your tasks are stored locally in %APPDATA%\Edgewise with atomic writes and 20
daily backup snapshots. Source code & checksums:
https://github.com/KennyMcSimpson/Edgewise
