Qingdan 1.2.0 — Quick Start (Windows x64 Portable)
==================================================

Qingdan is an ambient Windows deadline bar that stays within sight without
getting in the way. Completely offline — no account, no cloud sync, no telemetry.

HOW TO LAUNCH
-------------
1. Extract the entire ZIP archive to a permanent folder (do not run from inside
   the ZIP preview).
2. Double-click "Qingdan.exe" (or "Launch-Qingdan.cmd").
3. Keep all neighboring runtime files beside Qingdan.exe.

KEY FEATURES IN 1.2.0
---------------------
- Natural-Language Quick Capture:
    "Submit draft fri 18:00 !"       -> Friday 18:00, marked important
    "Review PR +2h"                  -> 2 hours from now
    "Standup weekdays 09:00"         -> Mon-Fri recurring routine
    "pin: Always verify checksums"   -> Pinned note on the top shelf
    Click "Raw" in the live preview bar to keep your exact literal title.
- Screen-Share Stealth (Eye-Off button):
    Hides Qingdan from Zoom, Teams, Discord, OBS, and Windows screenshots while
    staying visible to you.
- Ghost Click-Through Mode (Ctrl+Alt+G):
    Turns the bar into a semi-transparent click-through overlay over fullscreen
    IDEs or PDFs. Press Ctrl+Alt+G, Esc (when focused), Ctrl+Alt+Q, or click the
    system tray icon to exit safely.
- Single-Task Focus Strip (Crosshair button on any task):
    Collapses to a 132px strip with a drift-free 25:00 timer, pausing auto-tuck
    until you complete or exit.
- 1-Click Snooze (+1h / Tmr) with Undo (Ctrl+Z) & 2px DDL Runway Bar.
- Drag & Drop any text or URL onto the window or 46px edge tab to capture.
- Export Tasks as Markdown (.md) or JSON Backup from Settings.

GLOBAL SHORTCUTS
----------------
- Ctrl+Alt+Q : Show / Hide Qingdan and focus Quick Add
- Ctrl+Alt+G : Toggle Ghost Click-Through overlay
- Ctrl+N     : Open Detailed Task Editor
- Ctrl+F     : Search titles and notes
- Ctrl+Z     : Undo last task action

DATA & PRIVACY
--------------
Your tasks are stored locally in %APPDATA%\Qingdan with atomic writes and 20
daily backup snapshots. Source code & checksums:
https://github.com/KennyMcSimpson/qingdan
