轻单 Qingdan 1.1
轻一点，把重要的事留在桌边。

【开始使用】
1. 把压缩包“全部解压”到一个固定文件夹。
2. 双击 Qingdan.exe 即可，也可以点“启动轻单.cmd”。
3. 不用注册，不用安装 Node、Python；首次启动是空清单。
适用 Windows 10 / 11 的 x64 电脑。请保留整个文件夹，不能只拿走 EXE。

【怎么记】
底部直接输入，回车添加。
点输入框右侧图标，可写备注、DDL、重要标记。
点标题可编辑；点左边小方框完成；误操作可以点下方的撤销箭头。
长期目标、注意事项放在“常驻”，一直挂着，没有 DDL，不会自动消失。
不需要的常驻提醒可以在编辑界面“归档”。

【每日 / 每周提醒】
“循环”分类中输入并回车，选择每天、工作日（周一至周五）或每周。
设置首次日期和提醒时刻；每周采用所选日期的星期。
在指定时刻提醒一次。完成只完成本次，下一次会自动安排，并保留完成记录。
新周期自动更新，错过的不会堆积；历史完成记录可清理，刚完成的一次可撤销。
停止循环：编辑时把重复改为“不重复”，或删除循环事项。
工作日不包含法定节假日 / 调休日历。提醒需要程序运行。
常驻提醒固定在全部清单顶部，可以折叠，默认显示两条，可查看全部。

【DDL 会变色】
剩余超过 3 天：柔和绿色。
剩余 3 天以内：琥珀色。
剩余 24 小时以内：橙色。
超过截止时间：红色，并显示已逾期多久。
在设置中可以自选提前几天 / 几小时预警。颜色每 15 秒自动刷新。
日期按电脑本地时区设置，默认当天 23:59，可以自行改时间。

【悬浮窗】
拖顶部移动，拖边缘调大小。
图钉：置顶开关。
贴边按钮：收成屏幕边缘的小标签，点击标签展开。可拖动标签顶部小握柄。
切换到其他窗口后默认自动贴边，设置里可以关闭；正在编辑 / 选择备份时不会收起。
底部月亮：隐藏 15 分钟，到时只恢复侧边标签，不抢焦点。
向上图标：收成小条，保留最近 DDL 和预警色；点小条展开。
减号：收进右下角系统托盘，程序继续运行。
Ctrl + Alt + Q：唤回 / 隐藏。托盘图标可能藏在系统的小箭头里。
真正退出：右键托盘图标 > 退出轻单，或设置页底部“完全退出轻单”。

【其他快捷键】
Ctrl + N：详细添加。
Ctrl + F：搜索标题和备注。
Ctrl + Z：撤销上一步（焦点在文本框里时，是撤销输入）。
Esc：关闭编辑或设置；搜索时关闭搜索。

【保存和备份】
自动保存到 %APPDATA%\Qingdan，关闭 / 重启不会清空。
设置页可导出 JSON 备份、恢复备份、打开数据文件夹。
恢复备份会先确认，并备份原数据；可以撤销。
程序包可发给朋友，个人清单不会随程序文件夹一起走。
最多保存 5000 条记录；最近 30 次操作可撤销，重启后撤销历史清空。

【开机启动 / 通知】
开机启动默认关闭，可在设置中开启。开启前先固定程序文件夹位置。
移动程序后请重新开关一次开机启动，更新路径。
提醒只在程序运行时工作：托盘中可以继续提醒，完全退出 / 关机后不会提醒。
一次性 DDL 的紧急阶段和逾期阶段各提醒一次；循环事项在指定时刻提醒一次。
Windows 勿扰模式可能不显示系统提醒。

【从 1.0 升级】
先导出备份、完全退出旧版，再把新版完整解压到固定文件夹。
仍读取 %APPDATA%\Qingdan，旧待办、备注、完成状态和外观设置会保留。
继续使用新版编辑，旧程序不能保留新增循环字段。
开机启动已启用时，在新版中重新开关一次以更新路径；开机从侧边标签启动。
