# 轻单 · Qingdan

轻一点，把重要的事留在桌边。

一个供 Windows 10 / 11 x64 使用的本地悬浮待办小应用。无账号、无服务器、无云同步。暖纸 / 夜色两套外观，鼠尾草绿 / 雾蓝 / 豆沙三种点缀色。图标和插画为本项目原创矢量资源。

## 直接使用

1. 把整个压缩包解压到一个固定文件夹。
2. 双击 `Qingdan.exe`，或双击 `启动轻单.cmd`。
3. 在底部输入一件事并回车；点右边的小调节图标可以添加 DDL、备注和重要标记。

运行环境已包含在压缩包里，不需要安装 Node.js、Python 或其他开发工具。必须保留 EXE 旁边的资源、DLL 和 `resources` 文件夹；请勿只复制一个 EXE，也不要直接在压缩包预览里运行。

## 清单怎么用

| 想做什么 | 操作 |
| --- | --- |
| 随手添加 | 底部输入，按回车 |
| 添加截止时间 / 备注 | 底部右侧图标，或 `Ctrl+N` |
| 修改记录 | 点击标题或行右侧的 `…` |
| 完成待办 | 点击标题前的小方框 |
| 恢复已完成 | “完成”分类中再次点击方框 |
| 长期挂着 | “常驻”分类中添加，或编辑时选“长期提醒” |
| 每日 / 每周提醒 | “循环”分类中添加，选择周期、首次日期和提醒时刻 |
| 收起长期提醒 | 打开该条记录，点击“归档这条提醒” |
| 删除 | 打开记录，点击左下角“删除”；可以撤销 |
| 搜索标题与备注 | 右上方搜索按钮，或 `Ctrl+F` |
| 撤销 | 左下方状态栏右侧的回转箭头，或 `Ctrl+Z`（非输入框内） |
| 移动悬浮窗 | 拖动最上面的应用标题栏 |
| 调整大小 | 拖动窗口边缘或角落 |
| 置顶开关 | 顶部图钉，或设置 / 托盘菜单 |
| 收成小条 | 顶部向上图标；点击小条内容即可展开 |
| 贴边收起 | 切换到其他窗口自动收起，或点顶部贴边按钮；点击标签展开 |
| 暂时隐藏 | 底部月亮按钮隐藏 15 分钟，到时只恢复侧边标签 |
| 隐藏到托盘 | 顶部减号；系统关闭操作也会收进托盘 |
| 重新打开 | 点击系统托盘里的轻单，或 `Ctrl+Alt+Q` |
| 完全退出 | 设置页底部，或右键托盘图标选择“退出轻单” |

小条默认展示未完成事项中截止时间最早的一条；没有 DDL 时展示重要待办、普通待办或长期提醒。已逾期的事项会留在清单中，直到手动完成或删除。

同一分组内，“重要”记录优先，其次按截止日期和创建时间排列。长标题和备注会在列表中适度截断，点击后可以看完整内容。

## 循环提醒与常驻提醒

循环适合按时做的小事：在“循环”分类中输入并回车，或在详细编辑器的“重复”中选择每天、工作日（周一至周五）或每周。每周采用所选首次日期的星期。选择本机时间，保存前会显示下一次安排。

到指定时刻提醒一次，点完成只完成本次并自动排到下一次；完成分类中保留本次记录。刚完成的一次可以用撤销恢复；历史记录可删除或批量清理，不会停止循环。停止循环可将重复改为“不重复”，或删除循环事项。

跨入新周期时自动更新，即使上一期没完成也会继续提醒；错过的周期不会补出一串任务。周末不安排工作日提醒，未包含法定节假日或调休日历。跨夏令时会用日历运算保留本机时刻；遇到不存在的时刻，系统会调整到有效时间。

常驻适合长期目标和注意事项，没有截止时间。“全部”页面中固定在滚动列表上方，显示两条，重要提醒优先。点击区块标题可折叠，点“查看全部”进入常驻分类；点击标题编辑，手动归档后才会离开顶部。折叠状态会保存。

## 窗口主动让开

默认切到其他窗口后约一秒贴到最近的屏幕左右边缘，变成 46 像素宽的标签。顶部小握柄可以拖动标签；点击图标 / 文字即可展开。展开恢复之前的尺寸，位置会留在标签旁；标签可见时保持置顶，展开时遵循你的置顶开关。

正在编辑或选择导出 / 恢复文件时不会自动收起。设置中的“不用时自动贴边”可以关闭；手动贴边按钮仍可用。底部月亮按钮隐藏 15 分钟，到时只恢复标签，不抢焦点。托盘或 `Ctrl+Alt+Q` 提前唤回会取消本次隐藏计时。小条模式和长期隐藏到托盘也保留。

## DDL 自动变色

| 剩余时间（默认） | 颜色 | 显示 |
| --- | --- | --- |
| 超过 3 天 | 柔和绿色 | 剩余时间、具体日期与时刻 |
| 24 小时以上、3 天以内 | 琥珀色 | 临近预警 |
| 24 小时以内 | 橙色 | 紧急预警 |
| 已到期 / 超时 | 红色 | 刚刚到期 / 已逾期多久 |
| 长期提醒 | 当前主题的柔和点缀色 | 不参与倒计时 |

设置中可以把临近预警改成提前 1 / 3 / 7 / 14 天，把紧急预警改成提前 6 / 12 / 24 小时。若两个阈值重合，紧急颜色优先。颜色在窗口打开时每 15 秒更新，重新显示窗口时也会更新。

日期按本机时区输入；只改日期时，默认截止时间为当天 23:59。保存的是一个明确的时间点。跨时区使用时，显示会换算成本机时区；系统时间也会影响倒计时。

开启“到期提醒”后，一次性 DDL 在进入紧急 / 逾期阶段时各提醒一次，循环事项在指定时刻提醒一次。运行中每 30 秒检查，休眠恢复时也检查；隐藏到托盘后继续工作。完全退出程序或电脑关机时不提醒。Windows 的勿扰模式、通知设置可能使系统提醒不可见，清单内的变色不受影响。

## 自动保存与备份

数据保存在 `%APPDATA%\Qingdan`。设置里的“打开数据文件夹”可直接打开它。

- `qingdan.json`：当前记录、外观和窗口位置。
- `qingdan.json.bak`：前一次成功写入的副本。
- `backups`：每日快照，以及恢复备份 / 清理已完成前的快照，最多保留 20 份。
- `error.log`：有错误时的诊断记录，不会上传。

保存采用临时文件写入、刷盘、同目录替换。主文件异常且备份可用时会自动恢复并提示；不会直接把无法读取的数据当成空清单覆盖。

需要迁移电脑时，在设置中“导出备份”，然后在新电脑“恢复备份”。恢复会明确确认替换，并先备份当前记录；可以撤销。导出的文件含清单及备注，请按你自己的文件习惯保管。

程序包可以发给朋友。**清单不会跟着程序文件夹自动复制**，每个人的数据都在各自的 AppData；要共享清单，请另行导出 JSON 备份。

最近 30 次添加、修改、完成、删除、导入等操作可撤销，撤销历史只在本次运行中保留。最多 5000 条记录，标题最多 160 字，备注最多 5000 字。

## 启动和退出

开机启动默认为关闭，由你在设置中开启。启用之前，先把程序文件夹放在固定位置；之后移动程序，请重新开关一次“开机启动”以更新路径。

快捷键 `Ctrl+Alt+Q` 如果被其他软件占用，设置中会提示，托盘仍可使用。Windows 系统托盘可能把图标收在向上的小箭头里。

从 1.0 升级请先导出备份、完全退出旧程序，再完整解压新版。数据目录保持不变，旧清单和外观设置会自动读取。请使用新版继续编辑，旧程序不能保存新增的循环字段。开机启动已开启时，请在新版中重新开关一次以更新路径；开机启动会从侧边标签开始。

## 源码和开发

便携包中的源码位于 `resources/app`。`src/main.js` 负责原生窗口、托盘、提醒、备份和受限制的 IPC；`src/model.js` 负责截止逻辑与状态校验；`src/store.js` 负责持久保存；`src/renderer.js` 和 `src/styles.css` 负责界面。

没有运行时第三方 JavaScript 依赖。Electron 固定为 44.4.5，构建使用官方发布包，并对照官方 `SHASUMS256.txt` 校验。

开发机可安装 Node.js 后执行 `npm install` 和 `npm start`。`npm test` 运行核心测试。完整界面测试额外需要 Playwright，设置 `ELECTRON_BINARY` 指向 Electron 可执行文件后运行 `npm run test:ui`。Linux 测试环境需要显示服务器；测试脚本的 `--no-sandbox` 仅用于容器中的测试启动，交付的 Windows 启动命令不会设置它。

重新打包请使用 `scripts/package_windows.py`，按其说明提供官方 Windows x64 运行包及校验文件。EXE 图标与版本资源由 `scripts/brand_exe.mjs` 写入；构建工具用 resedit 3.1.0、Pillow。构建依赖与测试依赖均不需要用户安装。
