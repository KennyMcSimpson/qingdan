# Qingdan (now Edgewise) 1.1.0

A more practical everyday release of Qingdan (now Edgewise): set recurring tasks once, let the window move out of your way, and keep persistent reminders in a predictable place.

- **Recurring reminders**: daily, weekdays (Monday–Friday), and weekly, at a chosen local time. Completion records the current occurrence and schedules the next; new periods roll forward automatically so missed occurrences do not pile up.
- **Edge tab**: automatically tucks into a 46-pixel-wide tab when idle or when you switch away, and expands on click. Automatic tucking can be disabled in Settings; manual tuck, compact strip, and a 15-minute temporary hide are also available.
- **Top reminder shelf**: persistent reminders stay pinned above the scrolling task list in a collapsible shelf. Displays two items by default with one-click access to the rest, prioritizing reminders marked important.
- **Denser layout**: a dedicated recurring category, more usable list space in small windows, and protection against auto-tucking while editing or choosing backup files.
- **1.0 compatibility**: reads existing 1.0 tasks, notes, and appearance preferences from `%APPDATA%\Qingdan`. Export a backup before updating, then extract the complete new package.

Download `Qingdan-1.1.0-windows-x64.zip`, extract the entire folder, and launch `Qingdan.exe`. No development tools required. At 1.1.0 release, the application UI was in Chinese.

Reminders require the app to remain running and do not wake after exit or shutdown. Weekdays cover Monday through Friday and do not include a public-holiday calendar. Completed occurrences can be cleared, and the latest completion can be undone.
