# 轻单 Qingdan v1.0.0

## 中文

把重要的事留在桌边。轻单是一个 Windows 悬浮待办应用，支持 DDL 自动变色、长期提醒、小条模式和本地自动保存。

**使用：**下载 `Qingdan-1.0.0-windows-x64.zip`，完整解压后双击 `Qingdan.exe`。无需安装 Node.js 或 Python。

- 剩余 3 天内变琥珀色，24 小时内变橙色，逾期变红色，预警阈值可修改。
- 待办、备注、重要标记、长期提醒、搜索、归档、撤销。
- 置顶、拖动、缩放、小条、系统托盘、可选开机启动。
- 暖纸 / 夜色主题，本地保存、JSON 备份和恢复。

适用 Windows 10 / 11 x64；约 139 MiB，自带运行环境。`SHA256SUMS.txt` 提供下载文件校验值。

已通过 17 项核心测试和 17 项真实 Electron 窗口操作检查。初始界面检查在 Linux 中完成，尚未做 Windows 真机验证；首版无商业代码签名。系统提醒只在程序运行时工作。

## English

Keep the important things within sight. Qingdan is a floating Windows task list with color-coded deadlines, persistent reminders, a compact strip and local autosave.

**Start:** download `Qingdan-1.0.0-windows-x64.zip`, extract the whole archive and double-click `Qingdan.exe`. No Node.js or Python installation is needed.

- Amber within 3 days, orange within 24 hours, red after the deadline; thresholds are adjustable.
- Tasks, notes, important flags, persistent reminders, search, archiving and undo.
- Always-on-top window, dragging, resizing, compact mode, tray and optional login startup.
- Paper / Night themes, local storage and JSON backup / restore.

Targets Windows 10 / 11 x64. About 139 MiB including its runtime. Verify your download with `SHA256SUMS.txt`. The application interface is currently Chinese; repository documentation is bilingual.

17 core tests and 17 real Electron interaction checks passed. Initial UI checks used Linux, not a real Windows machine. This first release is unsigned; system reminders require the application to remain running.
