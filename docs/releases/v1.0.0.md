# Qingdan (now Edgewise) v1.0.0

Keep the important things within sight. Qingdan (now Edgewise) is a floating Windows task list with color-coded deadlines, persistent reminders, a compact strip, and local autosave.

**Getting started:** download `Qingdan-1.0.0-windows-x64.zip`, extract the entire archive, and double-click `Qingdan.exe`. No Node.js or Python installation is required.

- Amber within 3 days, orange within 24 hours, red after the deadline; warning thresholds are adjustable.
- Tasks, notes, important flags, persistent reminders, search, archiving, and 30-step undo.
- Always-on-top window, dragging, resizing, compact strip mode, system tray, and optional login startup.
- Paper / Night themes, local autosave, and JSON backup / restore.

Targets Windows 10 / 11 x64 (about 139 MiB including the bundled runtime). Verify your download with `SHA256SUMS.txt`. At v1.0.0 launch, the application interface was in Chinese and repository documentation was bilingual.

Verification: 17 core tests and 17 real Electron interaction checks passed. Initial UI checks used Linux rather than a physical Windows machine. This first release is unsigned, and system reminders require the application to remain running.
