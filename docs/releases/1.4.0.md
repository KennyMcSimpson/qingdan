# Edgewise 1.4.0

**Sharper ambient workflows, bug fixes, and faster keyboard capture** for the offline, edge-docked Windows deadline bar.

## What's New in 1.4.0

- **Compact + Ghost Mode Fixes & Adjustable Focus Strip**:
  - Compact + Ghost mode now displays a compact titlebar `GHOST` pill instead of pushing the 132px compact strip out of bounds.
  - Updated Ghost hints to accurately reflect click-through exit paths (`Ctrl+Alt+G`, `Ctrl+Alt+Q`, or system tray), adjusted toast placement in Compact mode, and synchronized Focus timer cleanup bidirectionally with edge tucking and window expansion.
  - Click the paused Focus timer to cycle `15 → 25 → 45 → 60m` presets (saved locally), extend active or finished sessions by `+5m`, track elapsed time on a 2px bottom progress bar, or launch Focus in 1 click straight from Compact mode.
- **Drag-and-Drop URL → 1-Click External Link Loop**:
  - Dropping a browser URL onto the window or 46px edge tab generates a clean readable title (e.g., `github.com · pull/123`) while preserving the full link in notes.
  - Active tasks, pinned notes, and the task editor now surface a 1-click open-link control backed by strict `http:` / `https:` URL validation in the main process.
- **Full-Width Narrow Rows & Peripheral Edge Countdown**:
  - Task row actions now render as a theme-aware hover/focus overlay, reclaiming ~35% horizontal title width at narrow desktop sizes.
  - The 46px edge tab replaces static vertical text with a live nearest-deadline countdown (`OVER`, `20m`, `3h`, `2d`, `CALM`) and accurate 3-tier urgency coloring (`overdue` → `urgent` → `soon` → `none`).
- **True Quiet Mode Alert Suppression, `+1w` Snooze & Routine `Skip`**:
  - Quiet breaks now suppress desktop balloons and notifications until the break ends or you resume from the tray, while recurring routines still roll cleanly in the background.
  - Choose `15 / 30 / 60` minute Quiet breaks in Settings or via the system tray submenu (with live `Quiet until HH:MM` tooltip and `Resume Now`).
  - Added `+1w` hover snooze for one-time deadlines and 1-click `Skip` for active routines to advance to the next occurrence without cluttering Completed (fully undoable).
- **Auto-Tuck-Aware Dismiss, Keyboard Flow & Cross-Tab Search Hints**:
  - `Ctrl+Alt+Q` and `Esc` (when clean) now respect Auto-tuck by tucking back into the 46px edge tab and returning focus to your previous app.
  - Added `Ctrl+1–5` tab switching, `↑`/`↓` row selection (`Enter` edit, `Space` toggle, `f` focus), `Ctrl+Enter` save from inside editor notes, and clickable `Also found:` cross-tab match pills while searching.
- **Richer Offline Natural-Language Quick Capture**:
  - Added whitespace-bounded ` // ` inline notes (never splitting `https://` URLs), spoken relative offsets (`in 30m`, `in 3 days`), ordinal dates (`Dec 5th`, `May 1st`), `next week`, guarded office time anchors (`eod`, `noon`, `morning`, `afternoon`, `evening`), and automatic Daily defaulting for time-only entries on the Repeat tab.
