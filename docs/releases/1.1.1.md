## 中文

轻单 1.1.1 修复 Windows 窗口置顶，并更新桌面运行环境的安全补丁。

- Windows 置顶状态与原生窗口保持一致，贴边、收起和恢复后仍可正常使用。
- Electron 更新至 44.9.1，包含窗口权限归属及证书处理的安全修复；同时更新下载工具依赖。
- 核心测试、真实窗口测试和 Windows / Linux 自动检查均已覆盖本次维护。

下载 `Qingdan-1.1.1-windows-x64.zip`，完整解压后启动 `Qingdan.exe`。现有清单、提醒和设置仍使用同一数据目录。更新时先退出旧版程序，再替换程序文件夹；不要删除自己的数据目录。

## English

Qingdan 1.1.1 fixes Windows always-on-top behavior and updates the desktop runtime with security patches.

- Keep the native Windows always-on-top state consistent through tuck, collapse, and restore interactions.
- Update Electron to 44.9.1 for permission attribution and certificate handling fixes, together with a patched download dependency.
- Validate the maintenance with core tests, real Electron window tests, and Windows / Linux checks.

Download `Qingdan-1.1.1-windows-x64.zip`, extract the complete folder, and launch `Qingdan.exe`. Existing tasks, reminders, and preferences continue to use the same data directory. Quit the previous version before replacing the application folder, and keep your data directory.
