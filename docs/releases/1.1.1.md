# Qingdan (now Edgewise) 1.1.1

Qingdan (now Edgewise) 1.1.1 fixes Windows always-on-top behavior and updates the desktop runtime with security patches.

- Keep the native Windows always-on-top state consistent through edge-tuck, collapse, and restore interactions.
- Update Electron to 44.9.1 for window permission attribution and certificate handling fixes, along with a patched download dependency.
- Verified with core unit tests, real Electron window tests, and automated Windows / Linux checks.

Download `Qingdan-1.1.1-windows-x64.zip`, extract the complete folder, and launch `Qingdan.exe`. Existing tasks, reminders, and preferences continue to use the same data directory. Quit the previous version before replacing the application folder, and keep your data directory intact.
