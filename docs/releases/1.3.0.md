# Edgewise 1.3.0

**Qingdan is now Edgewise** — a cleaner international name for the offline, edge-docked Windows deadline bar.

## What's New in 1.3.0

- **New Identity (`Edgewise`)**: Rebranded executable (`Edgewise.exe`), portable archive (`Edgewise-1.3.0-windows-x64.zip`), launcher (`Launch-Edgewise.cmd`), window/tray titles, PE version metadata, and documentation.
- **Automatic Non-Destructive Data Migration**: On first launch, Edgewise automatically copies existing tasks, settings, backups, and daily snapshots from `%APPDATA%\Qingdan` into `%APPDATA%\Edgewise` while leaving your previous `Qingdan` folder completely untouched.
- **Legacy Backup Compatibility**: Portable `.json` backups exported from Qingdan 1.x can be restored directly in Edgewise Settings.
- **Includes all 1.2.0 Ambient Features**: Offline natural-language quick capture with live chips & `Raw` escape, Screen-Share Stealth (`setContentProtection`), safe Ghost Click-Through (`Ctrl+Alt+G` / `Esc` / tray), drift-free 25-minute Single-Task Focus Strip, 2px DDL runway bar + 1-click `+1h`/`Tmr` snooze, drag-and-drop capture, and Markdown checklist export.
