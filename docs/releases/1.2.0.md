# Qingdan 1.2.0

A major usability and privacy upgrade turning Qingdan into a full English-first ambient deadline bar for Windows — still 100% offline with zero third-party JavaScript runtime dependencies.

## Highlights

- **Full English Interface**: Complete English desktop UI, tray menu, dialogs, and notifications.
- **Offline Natural-Language Quick Capture**: Type `Submit draft fri 18:00 !`, `Check GPU run +3h`, `Standup weekdays 09:00`, or `pin: Never force-push main` directly into the quick-add bar with a live chip preview and one-click `Raw` literal fallback.
- **Screen-Share Stealth**: Toggle **Hide from screen share** from the titlebar, tray, or Settings (`setContentProtection` / Windows `WDA_EXCLUDEFROMCAPTURE`) so your personal deadlines stay visible to you while remaining invisible in Zoom, Teams, Discord, and OBS screen shares.
- **Ghost Click-Through Overlay (`Ctrl+Alt+G`)**: Float Qingdan transparently above your IDE or browser without blocking mouse clicks; press `Ctrl+Alt+G` or click the tray icon to regain interaction.
- **Deadline Runway, 1-Click Snooze & Single-Task Focus Strip**:
  - Subtle 2px bottom runway progress bar on active deadline cards.
  - Hover micro-actions (`+1h` / `Tmr`) with full undo support.
  - Click the focus target on any task to lock the compact strip onto that single item with a quiet 25-minute timer.
- **Drag-and-Drop Capture & Markdown Export**: Drop any text or URL onto the window or 46px edge tab to capture instantly; export your list as a clean grouped Markdown checklist (`.md`) from Settings.
