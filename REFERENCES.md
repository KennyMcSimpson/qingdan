# References & Resources

The following projects were reviewed only to study floating task-list interaction patterns; no code or assets were copied:

- [LifePlanner / DailyPlanner](https://github.com/ReignDeve/DailyPlanner): frameless window, dragging, always-on-top, system tray, and themes.
- [Dayboard](https://github.com/FlameFront-end/dayboard): compact desktop task board and local persistence.
- [Desktop Tasks Widget](https://github.com/tanxestudio/Windows-desktop-Tasks-Widget): desktop window, priorities, deadlines, and tray settings.

## 1.1 Interaction References

The 1.1 daily-use update also draws interaction ideas from the following official product documentation; schedules, the reminder shelf, and edge-tab behavior are independently implemented with no copied code or artwork:

- [Todoist: Introduction to recurring dates](https://todoist.com/help/articles/introduction-to-recurring-dates-YUYVJJAV): scheduling the next occurrence on completion and skipping missed periods. Qingdan (now Edgewise) additionally rolls schedules forward automatically into new periods so uncompleted daily reminders do not stall.
- [TickTick for Windows](https://www.ticktick.com/windows): desktop sticky notes and mini window. Qingdan (now Edgewise) uses a collapsible top reminder shelf and a clickable edge tab.

The application mark, leaf illustration, and linear icons are original SVGs. The interface uses system fonts with no external images, online fonts, or tracking code. Tasks shown in screenshots are demonstration data and are not preloaded on first launch in release builds.
