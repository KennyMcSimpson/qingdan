# Changelog / 更新记录

## 1.0.0 — 2026-09-27

### 中文

轻单首个公开版本：悬浮置顶窗口、小条模式、托盘、待办与长期提醒、自动变色 DDL、备注与搜索、暖纸 / 夜色主题、本地保存、30 步撤销、JSON 备份和恢复。提供 Windows x64 便携包及中英双语仓库文档。

验证范围：17 项核心测试和 17 项真实 Electron 操作检查通过；初始 UI 测试使用 Linux，Windows 真机验证待补充。

### English

The first public release: an always-on-top floating window, compact strip, system tray, tasks and persistent reminders, color-coded deadlines, notes and search, Paper / Night themes, local autosave, 30-step undo, JSON backup and restore. Includes a portable Windows x64 distribution and bilingual repository documentation.

Verification: 17 core tests and 17 real Electron interaction checks passed. Initial UI testing used Linux; real Windows device verification is outstanding.
