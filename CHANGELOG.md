# Changelog / 更新记录

## 1.1.0 — 2026-09-30

### 中文

- 新增每天、工作日、每周循环提醒及指定提醒时刻；完成本次后安排下一次并保留完成记录，错过的周期不会堆积。
- 常驻提醒移到顶部可折叠区，重要提醒优先，默认显示两条，其余一键查看。
- 自动 / 手动贴边标签、15 分钟暂时隐藏；展开恢复尺寸，编辑与原生备份对话框阻止自动收起。
- 清单更紧凑，新增循环分类；兼容 1.0 的数据与设置。
- 新增 Windows / Linux 原生 Electron 操作检查和 Windows 自动打包；EXE 版本跟随应用版本。

### English

- Daily, weekday and weekly reminders at a chosen time. Completion records the current occurrence and schedules the next; missed periods do not pile up.
- Persistent reminders move to a collapsible top shelf, with important notes first and access to the full collection.
- Automatic / manual edge tab and a 15-minute hide. Expansion restores dimensions; editors and native backup dialogs prevent automatic tucking.
- Denser layout, a separate recurring category, and compatibility with 1.0 data and preferences.
- Native Electron checks on Windows / Linux and automated Windows packaging; executable metadata follows the app version.

## 1.0.0 — 2026-09-27

### 中文

轻单首个公开版本：悬浮置顶窗口、小条模式、托盘、待办与长期提醒、自动变色 DDL、备注与搜索、暖纸 / 夜色主题、本地保存、30 步撤销、JSON 备份和恢复。提供 Windows x64 便携包及中英双语仓库文档。

验证范围：17 项核心测试和 17 项真实 Electron 操作检查通过；初始 UI 测试使用 Linux，Windows 真机验证待补充。

### English

The first public release: an always-on-top floating window, compact strip, system tray, tasks and persistent reminders, color-coded deadlines, notes and search, Paper / Night themes, local autosave, 30-step undo, JSON backup and restore. Includes a portable Windows x64 distribution and bilingual repository documentation.

Verification: 17 core tests and 17 real Electron interaction checks passed. Initial UI testing used Linux; real Windows device verification is outstanding.
